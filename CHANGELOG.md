### Added
- Initial project structure
- Core architecture with process manager, file manager, scheduler, metrics, authentication, permissions
- Web dashboard with overview, servers, applications, Docker, websites, databases, files, backups, schedules, users, logs, settings
- CLI with init, start, stop, restart, status, logs, update commands
- Server management with resource limits and restart policies
- Application management with Git deployment
- Docker management (containers, images, volumes, networks, Compose)
- Minecraft server management (Vanilla, Paper, Purpur, Fabric, Forge)
- Live Minecraft console streaming
- File manager with browse, upload, download, edit, archive
- Backup system with scheduling
- Website reverse proxy with automatic HTTPS
- Database management (PostgreSQL, MySQL, MariaDB, SQLite)
- REST API with token authentication
- Multi-user support with role-based permissions
- Monitoring and alerting
- SQLite default database
- systemd service installation
